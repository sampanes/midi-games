4. Optional safe output probe

This sends one short note at the selected velocity to exactly one selected output. It then attempts Note Off, All Notes Off, and All Sound Off, and records whether every cleanup message succeeded. It never sends Program Change, bank select, clock, reset, NRPN, or SysEx.

First put wired headphones/speaker volume very low; disconnect the physical MIDI OUT unless you intend to test its receiver; and set ARP/latch, Note Repeat/latch, Scale, Chord, and sequencer playback off, sustain released, and octave neutral. If cleanup is uncertain, reconnect the endpoint, press Stop all test notes, and power-cycle the keyboard if anything still sounds.
